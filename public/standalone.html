FROM THE IDEA TO EVERYDAY LIFE

Here’s what it takes.

The interface is one part. The connections and delivery services make it work.

FOR YOU · IPHONE + GOOGLE

Your private assistant

  1. A private server

    Run the included Node server on an HTTPS host with persistent storage. Keep it running for scheduled texts.

  2. A Google Cloud project

    Enable Gmail and Calendar APIs, create a Web OAuth client, register the callback URL, and add yourself as a test user.

  3. An AI API account

    Set a server-side API key and a supported model. The assistant proposes actions; you approve them.

  4. A texting number

    Configure Twilio, the inbound webhook, your verified phone number, messaging consent, and applicable sender registration.

  5. Add to your Home Screen

    Open your HTTPS app in Safari, then Share → Add to Home Screen. You don’t need an App Store release for this.

FOR CUSTOMERS · A PUBLIC PRODUCT

A service you can sell

  1. Separate customer accounts

    The included live server is single-user. Replace its personal login with production authentication and enforce data isolation for every record, job, and connection.

  2. Provider approval

    Complete Google verification for the scopes you request. Server use of restricted Gmail data can require a security assessment.

  3. Reliable delivery

    Add durable queues, retries, monitoring, backups, quotas, billing, and failure notifications. Test changes around time zones and daylight saving time.

  4. A clear customer agreement

    Define privacy, data retention/deletion, consent, pricing, cancellation, support, and what the assistant can do. Review launch requirements for your markets.

  5. Prove the paid experience

    Run a small consenting beta. Measure whether it reduces the work of remembering, and whether users return and pay.

What’s actually in this build?

Google is the first live provider. Microsoft, Apple/iCloud, reading your existing phone texts, and phone calls are not implemented. SMS conversations use a dedicated assistant number; they do not read your iPhone’s Messages history.

Detailed setup and current verification limits are included in the source README and SETUP.md.
